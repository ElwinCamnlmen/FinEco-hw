# HW02-1：股票收益与组合风险

## 数据与版本

2026-09-27 下载并冻结，收益样本为 2021-01-04—2026-09-16，2020-12-31 提供基期价格和首日权重。接口及参数见 `data/manifest.json`，AKShare 1.18.97。

- 腾讯不复权行情：`stock_zh_a_hist_tx(adjust="")`；成交额单位为人民币元。
- 新浪前后复权因子：`stock_zh_a_daily(adjust="hfq-factor"/"qfq-factor")`。主分析以原始价乘后复权因子，并与前复权因子计算的收益互相核验。
- 腾讯前复权行情仅用于同样本、同权重的敏感性比较，未混入主收益序列。
- 东方财富每日历史总市值：`stock_value_em`，单位为元；总股本单位为股。
- 东方财富公司概况：`RPT_F10_ORG_BASICINFO` 的 `EM2016` 一级行业和上市日期。
- 宁波银行、长江电力是初始候选覆盖检查数据，未进入最终十股组合。最终选股表见 `results/selection.csv`。

## 从新目录复现

1. 将完整 `FinEco-hw` 文件夹复制或下载到新目录，保留内部结构。
2. 使用 Python 3.12 环境，安装 `hw02-1/requirements.txt`。例如：

```bash
python -m pip install -r hw02-1/requirements.txt
```

3. 在 Jupyter 或 VS Code 打开 `hw02-1/hw02-1.ipynb`，选择上述环境，重启内核并运行全部单元格。工作目录可为本题目录或仓库根目录。
4. 检查源数据指纹、主键和权重断言通过，确认七张主要图及全部表格生成。

中文字体支持 Arial Unicode MS、PingFang SC、Microsoft YaHei、SimHei、Noto Sans CJK SC 等。Linux 如缺少中文字体，可使用 Noto Sans CJK SC；Notebook 会明确报告字体缺失，不静默生成乱码。

`code/download.py` 只用于另行获取公开快照；复现当前结果不需要执行它。脚本默认不覆盖已有快照。未来重新取数可能改变复权历史和结果，不能把新数据冒充当前快照。所有分析和关键计算在 Notebook 中呈现。

## 预期主要输出

- 10 只股票、5 个行业、每股 1,385 个价格观测和 1,384 个日收益。
- 等权组合累计收益约 3.8832%，年化收益约 0.6961%，年化波动约 16.4164%，最大回撤约 26.4530%。
- 市值加权累计收益约 -29.6544%，年化收益约 -6.2039%，年化波动约 22.1103%，最大回撤约 46.6470%。
- `results/` 保存选股、审计、个股统计、相关系数、每日权重、组合指标、复权敏感性和七张 PNG 图。

结果按日收益 252/T 几何年化；不删日、不填收益、不缩尾；每日目标权重、忽略成本。具体口径和局限见 Notebook。
